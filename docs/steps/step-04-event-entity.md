# Step 04 - Event entity (creates the events table)

## Checklist
- [x] Create a new package `entity` under `../../backend/src/main/java/com/diego/events`
- [x] Create the enum `EventStatus` in `entity`
    - 3 values: `PENDING_REVIEW`, `PUBLISHED`, `REJECTED`
    - New > Java Class > pick "Enum"
- [x] Create the class `Event` in `entity` with these fields
    - `id` (Long): the primary key, auto-generated by the database
    - `title` (String): required
    - `description` (String): optional
    - `eventDate` (LocalDateTime): required
    - `capacity` (int): required
    - `status` (EventStatus): required, stored as text
    - `organiserId` (String): required
- [x] Add the annotations on the class and fields
    - Class: marks it as a database entity, and name the table `events`
    - `id`: marks it as the primary key, plus auto-generate it
    - `status`: store the enum as text (STRING), not as numbers
    - Required fields: not nullable
- [x] Generate getters and setters for every field
    - Click inside the class, press Alt+Insert > Getter and Setter > select all > OK
- [x] Restart the backend
- [x] Check the table exists

## Notes / gotchas
- We’re declaring EventStatus as an enum because it defines a fixed set of allowed statuses and prevents variables of that type from holding arbitrary values.
